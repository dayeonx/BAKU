행사 등록부터 참여 신청, 정산, 후기, 앨범까지 — 우리 동아리 활동의 모든 흐름을 하나의 앱에서.

지금 체험하기 → 앱으로 설치하는 법

왜 BAKU를 만들었나요?

엑셀 시트와 단톡방에 흩어져 있던 동아리 운영 업무를 한곳에 모으고 싶어서 직접 기획하고 만들었어요.

🎯

왜 만들었나

행사 등록, 참여자 파악, 정산 확인이 매번 엑셀·카톡으로 흩어져서 헷갈렸던 문제를 해결하려고 만들었어요.

🧑‍🤝‍🧑

누구에게 필요한가

회장단은 행사 승인·정산·회원 관리를, 일반 부원은 신청·정산 확인·후기 작성을 이 앱 하나로 처리해요.

🕐

언제 사용하나

새 활동을 기획할 때부터 활동이 끝나고 앨범에 추억이 쌓이는 순간까지, 전 과정에서 사용해요.

핵심 기능 흐름

하나의 활동이 만들어지고 기록으로 남기까지, BAKU 안에서 이렇게 이어져요.

1

📅 주최 등록 캘린더

정기주최부터 자유주최, 신환회·엠티·빵지순례 같은 특별 활동까지, 카테고리에 맞는 정보를 입력해 캘린더에 일정을 등록해요. 임원진 승인을 거쳐 확정돼요.

↓
2

✋ 참여 신청 선착순

등록된 활동에 부원들이 신청해요. 정원이 차면 마감되는 선착순 방식이라 신청 현황을 실시간으로 확인할 수 있어요.

↓
3

💰 정산 2단계 확인

참여자가 입금 사실을 자가 신고하면 임원진이 확인 처리하는 2단계 구조예요. 쿠폰이 있다면 정산에 바로 적용할 수 있고, 마이페이지에서 대기·완료 상태를 바로 볼 수 있어요.

↓
4

✍️ 후기 등록 활동 종료 후

활동이 끝나면(정확한 종료 시각 기준) 참여자가 후기를 남길 수 있어요. 짧은 소감이 아니라 100자 이상의 진짜 후기를 쓰도록 했고, 사진은 앨범에 따로 올려요.

↓
5

📷 앨범 학기별 아카이브

활동 사진을 인스타그램 피드처럼 모아 보고, 대표 사진은 원하는 위치로 크롭할 수 있어요. 레시피와 참고 링크도 함께 남겨서 학기별로 우리 동아리 활동이 예쁘게 쌓여요.

🔔 알림벨 🎟️ 쿠폰 관리 📋 부서별 업무 보드 👥 회원 관리 📁 구글 드라이브 연동 📱 홈 화면 앱 설치(PWA)

🍎 아이폰(Safari)에서 앱으로 추가하기

  1. Safari로 baku-mu.vercel.app에 접속해요.
  2. 화면 하단의 공유 버튼(사각형 위에 위쪽 화살표 아이콘)을 눌러요.
  3. 메뉴를 아래로 내려서 "홈 화면에 추가"를 선택해요.
  4. 이름을 확인하고 오른쪽 위 "추가"를 눌러요.
  5. 홈 화면에 생긴 BAKU 아이콘을 누르면 앱처럼 전체 화면으로 실행돼요.

※ 반드시 Safari로 접속해야 "홈 화면에 추가" 메뉴가 보여요. (크롬 등 다른 브라우저에는 없을 수 있어요)

🤖 안드로이드(Chrome)에서 앱으로 추가하기

  1. Chrome으로 baku-mu.vercel.app에 접속해요.
  2. 오른쪽 위 점 세 개(⋮) 메뉴를 눌러요.
  3. "앱 설치" 또는 "홈 화면에 추가"를 선택해요. (기기마다 문구가 조금 달라요)
  4. 안내창에서 "설치"를 눌러요.
  5. 홈 화면 또는 앱 서랍에 생긴 BAKU 아이콘으로 바로 실행해요.

※ 접속 중 하단에 "앱 설치" 배너가 자동으로 뜨기도 해요. 그럴 땐 배너를 눌러도 돼요.

기본 골격을 만든 1주차와, 실제로 쓸 수 있도록 다듬은 2주차의 차이예요.

WEEK 1 · 골격 만들기

로그인부터 기본 페이지까지

  • Supabase 인증 기반 로그인·회원가입
  • 메인 홈, 캘린더, 앨범 기본 구조
  • 행사 등록·승인, 참여 신청 흐름 1차 구현
  • 임원진 전용 관리자 메뉴, 마이페이지 기본
WEEK 2 · 실사용 다듬기

진짜 쓸 수 있는 앱으로

  • 정산을 "자가 신고 + 임원 확인" 2단계로 고도화
  • 업무 관리를 프로젝트/단계 구조로 재설계
  • 쿠폰·구글드라이브 연동, 알림벨 추가
  • PWA 지원 + 모바일 헤더 메뉴 신규 추가
  • 한글/공백 파일명 업로드 오류 등 버그 수정
  • 실제 사용 피드백을 반영한 문구·UX 반복 정리

개발 과정의 시행착오와 배운 점

만들면서 실제로 부딪히고 고친 문제들이에요.

🗂️

한글·공백이 든 파일명 업로드 실패

영수증 사진, 참여자 명단 엑셀 파일명에 한글이나 공백이 들어가면 Supabase Storage가 업로드를 거부했어요.

→ 업로드 전 파일명을 영문·숫자로 안전하게 바꿔주는 함수를 만들어 모든 업로드 지점에 적용했어요.

⏱️

"활동 종료"를 날짜로만 판단했던 문제

날짜만 기준으로 삼으니 활동이 오후 늦게 끝나도 자정이 지나야 정산·앨범이 열려서 실제 흐름과 어긋났어요.

→ 종료 날짜와 시각을 함께 비교하는 로직으로 통일해서, 활동이 끝나는 정확한 순간에 맞춰 열리도록 고쳤어요.

👥

업무 담당자를 부서 하나로만 설계했던 문제

처음엔 업무마다 담당 부서를 하나만 고를 수 있었는데, 실제로는 여러 부서가 함께 협업하는 업무가 많았어요.

→ 담당자를 여러 부서·이름을 자유롭게 조합할 수 있는 구조로 리팩터링했어요.

🔐

권한 관리는 결국 데이터베이스 레벨에서

화면에서만 버튼을 숨기는 방식으로는 진짜 보안이 되지 않는다는 걸 깨달았어요.

→ Supabase RLS(행 단위 보안 정책)로 임원진·주최자·참여자 권한을 데이터베이스에서 직접 검증하도록 만들고, 기능이 추가될 때마다 SQL 마이그레이션을 작성해 반영했어요.
